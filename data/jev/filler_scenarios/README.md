# 건강기능식품 쇼핑몰 AI 상담원 채움말 분류 예제

- `scenarios.jsonl`: 발화 50개를 한 줄당 하나의 JSON 객체로 저장. 학습 예제 또는 평가 데이터로 변환하기 편함.
- `scenarios.json`: 같은 데이터를 JSON 배열로 저장. 미리보기/개발 편의용.
- `labels_and_policy.json`: intent, dialogue_state 정의 및 필러 안전 원칙.

## 필드
- `utterance`: 고객 가상 발화
- `intent`: 주요 업무 분류
- `dialogue_state`: 정정/정보 부족/다중 의도 등 상태
- `filler_text`: 짧은 응답 후보. 공백이면 침묵 유지 권고
- `recommended_next_step`: 상담 로직의 다음 동작 힌트(실제 API 명세와 무관)
- `filler_allowed`: 이 예제에서 채움말을 출력해도 되는지
- `synthetic`: 모두 가상 생성 예제임을 표시

## 사용 주의
이 파일은 **Jev 전용 파인튜닝 파일이 아닌 일반 JSONL 시나리오 예제집**입니다. Jev API/SDK가 요구하는 질문 유형과 입력 구조로 변환해 사용하세요. 또한 50개는 모델 성능을 검증할 충분한 규모가 아니므로 음성 다양성/소음/오인식 데이터를 추가해야 합니다.

실제 빈도 통계가 없으므로 의도별 발생 확률은 임의로 붙이지 않았습니다. 분류 확률은 모델이 발화별로 반환하는 값을 활용하되, 보정되지 않은 확률로 실행 권한을 결정하지 마세요.

건강 우려 발화에서 약물 복용 지속 여부를 임의로 안내하지 않고, 응급 징후는 즉각적인 안전 안내가 우선입니다. 실제 운영에서는 기업 응대 매뉴얼 및 대회 규칙을 따라야 합니다.
